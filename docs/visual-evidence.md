No image uses AI-generated pixels, invented findings or retouched result values. Original captures and rendering records remain private under `EV-PORTFOLIO-VISUALS-V22` and `EV-HARTWELL-REPORT-REFRESH`. The three current hunt images are byte-for-byte native browser captures; no post-capture pixel editing or metadata removal was needed.

The [image manifest](visual-evidence.json) records exact SHA-256 hashes, dimensions, sizes, sources and framing. Repository checks accept only these seven paths and exact bytes, reject PNG metadata/extra chunks and enforce size limits. Other screenshots and source attachments remain ignored. These checks do not inspect pixel meaning; any replacement requires another visual disclosure review.
